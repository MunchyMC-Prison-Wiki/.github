# MunchyMC Prison Wiki

Welcome to the Unofficial MunchyMC Prison Wiki!

The project is mainly run by [iona](https://github.com/eeonaa) with occasional assistance from [softfaulty](https://github.com/softfaulty),
We are dedicated to documenting as much information as possible about the prison gamemode on MunchyMC!

The main goal is to make everything about prison easy to find and understand, whether you're brand new or an experienced player looking for information on something specific.

## Contributing

The wiki is an opensource project, so please send pull requests! We actively look over PR's, so don't be shy! If you feel like you can improve the site, show us how!
