# MunchyMC Prison Wiki

welcome to the munchymc prison wiki!

we are a 2 person project dedicated to documenting as much information as possible about the prison gamemode on munchymc!

our main goal is to make everything about prison easy to find and understand, whether you're brand new or an experienced player looking for information on something specific.

## Contributing

the wiki is mainly maintained by two people, [softfaulty](https://github.com/softfaulty) and [iona](https://github.com/eeonaa), however, as an opensource project, we'll always accept pull requests for anything thats missing, outdated or incorrect!
